Provides useful 3-day forecast while keeping response size manageable. 72 hourly timestamps per variable per coordinate.---## Batching Recommendation| Batch Size | Batches | Rationale ||------------|---------|-----------|| 100 | 27 | Maximum efficiency, risk of large responses || **50** | **54** | **Balanced — RECOMMENDED for the current build** || 25 | 107 | Conservative, more API calls || 10 | 267 | Very conservative, many calls |**Recommendation:** 50 coordinates per batch. Open-Meteo supports multiple coordinates per request. 50 per batch keeps response sizes manageable and allows rate-limit protection between batches.---## Rate-Limit Safety Plan### Known Limits| Limit | Value | Protection ||-------|-------|------------|| Calls per day | 10,000 | Track daily count, pause if approaching || Calls per hour | 5,000 | Spread fetches over time || Calls per minute | 600 | Max 5 concurrent requests |### Safety Strategy1. **Fetch interval:** Full global refresh every 6 hours (4 fetches/day)2. **Batch size:** 50 coordinates per request3. **Estimated calls per fetch:** 54 (2664 / 50)4. **Estimated daily calls:** ~216 (54 x 4)5. **Headroom:** 216 / 10,000 = 2.16% of daily limit6. **Concurrent requests:** Max 5 with 1-second delay between batches7. **Backoff on 429/503:** Exponential backoff starting at 30 seconds8. **Retry on failure:** 3 attempts with exponential backoff (30s, 60s, 120s)### Critical Unknown**What counts as 1 API call?** Official docs do not specify. WO-WEATHER-S must measure:- Does 1 request with N coordinates count as 1 call or N calls?- Does requesting both `current` and `hourly` count as 1 or 2 calls?- Are there response headers indicating remaining quota?---## Request Parameter Summary| Parameter | Value | Rationale ||-----------|-------|-----------|| `latitude` | Grid coordinates (comma-separated) | Multiple coordinates per request || `longitude` | Grid coordinates (comma-separated) | Must match latitude count || `current` | 11 variables | All current build current weather fields || `hourly` | 12 variables | All current-build hourly weather fields || `temperature_unit` | `celsius` | Standard metric || `wind_speed_unit` | `kmh` | Kilometers per hour || `precipitation_unit` | `mm` | Millimeters || `timeformat` | `iso8601` | ISO 8601 timestamps || `timezone` | `auto` | Automatic timezone detection || `forecast_days` | `3` | 3-day forecast for the current build || `cell_selection` | `land` | Prefer land grid cells |
