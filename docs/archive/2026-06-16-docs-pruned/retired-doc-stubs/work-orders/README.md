# docs/work-orders

> **Classification:** WORK_ORDER
> **Last updated:** 2026-06-14

This folder is for **active/future work orders only**.

## Rules

- **Completed work orders are archived** under `docs/archive/`.
- Use `docs/control/WORK_ORDER_TEMPLATE.md` for creating new work orders.
- Do not keep completed work orders here. Move them to archive when done.
- Work orders here represent planned or in-progress work only.

## Related documents

- `docs/control/WORK_ORDER_TEMPLATE.md` — template for new work orders
- `docs/archive/` — where completed work orders are preserved
- `docs/README.md` — documentation map
